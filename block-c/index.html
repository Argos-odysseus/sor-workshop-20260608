Block C

Energy API

Backend solution for the agent build exercise. The GitHub Pages version documents the API and branch; the Express service should be run locally for live requests.

Run locally

git checkout argos/workshop-block-c-energy-api
cd agent/app
npm install
npm test
npm run dev

Endpoints

  • GET /housesList seeded houses.
  • GET /houses/:idGet one house.
  • GET /houses/:id/readingsList readings, with optional from and to ISO filters.
  • GET /houses/:id/readings/summaryReturn total, average, count, and daily averages.
  • POST /houses/:id/readingsAdd a reading with timestamp and kWh validation.
  • DELETE /readings/:idDelete a reading.
