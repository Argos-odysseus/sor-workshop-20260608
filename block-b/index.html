Block B

Gym Membership API

Backend solution for the code renovation exercise. This page is static because GitHub Pages cannot run the Express server; use the commands below to run it locally.

Run locally

git checkout argos/workshop-block-b-renovation
cd renovation/app
npm install
npm test
npm run dev

Endpoints

  • GET /membersList all members.
  • GET /members/:idGet one member with consistent not-found handling.
  • POST /membersCreate a member with input validation.
  • POST /members/:id/checkinCheck in with plan limit enforcement.
  • GET /members/:id/checkinsRead check-in history.
  • GET /members/:id/billingRead billing summary from service logic.
